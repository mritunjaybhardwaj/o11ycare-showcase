FOR DEVELOPERS & ON-CALL ENGINEERS

Find the logs that explain the incident.

“When an application request fails, I want to search across pods in one place so I can understand what happened without connecting to each pod.”

  1. Choose the incident’s time range in Grafana.
  2. Filter by namespace, pod, or container.
  3. Search an error or a logged request ID and read the surrounding records.

Give every team its own view.

FROM APPLICATION TO ANSWER

A clear path for every log.

o11ycare brings collection, buffering, forwarding, and search into a customer-hosted Kubernetes pipeline.

01 / COLLECT

Collect across nodes.

Vector agents tail container logs where your applications run.

Vector DaemonSet
02 / BUFFER

Make room for interruptions.

The aggregator uses a persistent disk buffer while delivery is unavailable, within its configured capacity.

Vector aggregator
03 / DELIVER

Control concurrent work.

The dispatcher validates tenant identity, bounds in-flight requests, and routes tenant-specific batches to Loki.

Go dispatcher
04 / INVESTIGATE

Search in one place.

Loki separates data by tenant. Grafana data sources supply the tenant identity for each query.

Loki + Grafana

Pipeline visibility: Vector, dispatcher, Loki, and Kubernetes state metrics flow separately to Mimir. Explore them in the Pipeline Operations dashboard.

WORKING TODAY

Log streaming, tenant-aware queries, and operational visibility

Pod-based tenant enrichment, tenant-specific batches, dispatcher validation and routing, Loki multi-tenancy, tenant-configured Grafana queries, and the Pipeline Operations dashboard. Earlier dispatcher-outage recovery was verified with 10,000 records.

NEXT: VALIDATION & OPERATIONS

Prove separation. Make it repeatable.

Two-way tenant-isolation validation, automated tenant checks, recovery testing with both tenants, operational alerts, and repeatable installation guidance remain next.

BEYOND MVP

Stronger operational guarantees

Customer-facing query access controls, ingestion authentication, per-tenant resource controls, noisy-neighbor isolation, automated scaling, and broader durability validation.
