01AVAILABLE TODAY

FOR DEVELOPERS & ON-CALL ENGINEERS

Find the logs that explain the incident.

“When an application request fails, I want to search across pods in one place so I can understand what happened without connecting to each pod.”

  1. Choose the incident’s time range in Grafana.
  2. Filter by namespace, pod, or container.
  3. Search an error or a logged request ID and read the surrounding records.
THE VALUE

Spend less time gathering evidence and more time resolving the issue.

Try a sample investigation →
02RECOVERY TESTED

FOR PLATFORM ENGINEERS

Keep an interruption from becoming a mystery.

“When delivery is interrupted, I want logs buffered and forwarded after recovery so teams can investigate what happened during the outage.”

  1. Observe failures and buffer usage in pipeline metrics.
  2. Restore the unavailable component and watch delivery resume.
  3. Verify expected test records with an automated recovery test.
THE VALUE

Build confidence in recovery with evidence, not just a green health check.

See the verified result →
03PLANNED FOR MVP

FOR PLATFORM ADMINISTRATORS & TEAMS

Give every team its own view.

“I want each team to access only its own logs, so we can share a logging platform while keeping clear data-access boundaries.”

  1. Assign trusted tenant metadata to workloads.
  2. Validate and route tenant-specific log batches.
  3. Let authenticated users query only their authorized tenant’s logs.
THE VALUE

Share the platform without sharing another team’s log data.

FROM APPLICATION TO ANSWER

A clear path for every log.

o11ycare brings collection, buffering, forwarding, and search into a customer-hosted Kubernetes pipeline.

01 / COLLECT

Collect across nodes.

Vector agents tail container logs where your applications run.

Vector DaemonSet
02 / BUFFER

Make room for interruptions.

The aggregator uses a persistent disk buffer while delivery is unavailable, within its configured capacity.

Vector aggregator
03 / DELIVER

Control concurrent work.

The dispatcher bounds in-flight requests and forwards batches to Loki.

Go dispatcher
04 / INVESTIGATE

Search in one place.

Loki stores the logs. Grafana gives your team a familiar way to explore them.

Loki + Grafana

Pipeline visibility: Vector internal metrics and Kubernetes state metrics flow separately to Mimir and Grafana.

KNOW WHAT YOU’RE TRYING

Useful today.
Clear about what’s next.

o11ycare is an early-stage POC. Explore a working pipeline and discuss your requirements before evaluating it for production.

WORKING TODAY

Collection, search, and tested recovery

Kubernetes log streaming, Grafana exploration, bounded dispatcher concurrency, and an automated dispatcher-outage test.

PLANNED FOR MVP

Multi-tenant data isolation

Tenant enrichment, batch validation, destination routing, isolated queries, and repeatable onboarding.

BEYOND MVP

Stronger operational guarantees

Ingestion authentication, per-tenant resource controls, noisy-neighbor isolation, automated scaling, and broader durability validation.
